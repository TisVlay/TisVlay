# Contextual-help follow-ups

Deferred polish for the GUI contextual-help overlay ([docs/gui/contextual-help.md](../gui/contextual-help.md)).

## Pencil double-affordance density

Some rows carry both an edit pencil (✎ hover tip) and an adjacent "i" toggletip (ⓘ). Reconsider whether the two glyphs per row read as cluttered, and whether the pencil's hover tip should fold into the "i" help.
